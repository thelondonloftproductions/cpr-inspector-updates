# CPR Inspector – update notices

This repository only holds `latest.json`, the small file CPR Inspector reads to tell
users a new version is available. It contains the latest version number, a short
"what's new" and a link to log in to Podia. No app downloads are hosted here.

**Do not rename or delete this repository**: installed copies of the app check
https://thelondonloftproductions.github.io/cpr-inspector-updates/latest.json

To announce a release: upload the new version to Podia first, then update
`mac.latest`, `released`, `headline` and `notes` in `latest.json`.
